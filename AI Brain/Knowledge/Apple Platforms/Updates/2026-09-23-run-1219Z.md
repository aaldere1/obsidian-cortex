## Findings reviewed

### 1. App Store Connect API 4.5 — new release

Apple's releases page now lists App Store Connect API 4.5 with a downloadable OpenAPI specification and release notes, dated 2026-09-22.

The pass did not infer a detailed 4.5 change set from undocumented assumptions. Canonical guidance instead records the new version and requires generated clients/automation to pin and diff the official OpenAPI specification before regeneration.

Canonical change: YES — created `Distribution/App-Store-Connect-and-Submission.md` and added API 4.5 to INDEX.
Action change: YES — added APPLE-018 for repositories that directly call App Store Connect API or generate clients from its specification.

### 2. On-Demand Resources deprecation — important missing canonical migration domain

Apple currently states that On-Demand Resources are deprecated starting with iOS 27, iPadOS 27, tvOS 27, and visionOS 27 and that support will be removed in a future release. Apple recommends migration to Background Assets. Foundation's `NSBundleResourceRequest` APIs are also marked deprecated with the instruction to use Background Assets instead.

Apple's current Background Assets guidance confirms that Managed Background Assets are available to apps targeting iOS/iPadOS/macOS/tvOS/visionOS 26 or later and can be self-hosted or Apple-hosted. Apple-hosted packs can be delivered separately from the app build through TestFlight/App Store, versioned independently, and updated without creating a new app version. Starting with the 27 OS generation, localized asset packs can be delivered separately according to language settings.

Canonical change: YES — created `Distribution/Background-Assets-and-ODR-Migration.md` and indexed the Distribution domain.
Action change: YES — added APPLE-017 as P0 for any project that still uses ODR/`NSBundleResourceRequest`.

### 3. September 2026 social-media submission requirement — important current distribution gap

Apple's current App Store guidance states that beginning September 2026 developers must indicate whether an app/game includes social-media capabilities to submit new versions or updates to the App Store or for notarization for alternative marketplace distribution.

Apple also states that if social-media capabilities are disabled for users under 13, developers need to use the Declared Age Range API at minimum to check user age ranges; the age-rating questionnaire and product behavior continue to determine the final rating/category behavior.

Canonical change: YES — recorded in `Distribution/App-Store-Connect-and-Submission.md`.
Action change: YES — added APPLE-019 for apps with feeds, posting, chat/community, or other social-media capability.

### 4. Swift Evolution SE-0551 — Span over a single value

SE-0551 entered active review on 2026-09-22 and runs through 2026-10-06.

The proposal adds single-value borrowing/mutation initializers for `Span`, `MutableSpan`, `RawSpan`, and `MutableRawSpan`, avoiding unnecessary copies and enabling noncopyable values. It also provides lifetime-aware alternatives to several single-value unsafe-pointer/unsafe-bytes adaptation patterns.

Canonical change: YES — added to `Swift/Evolution-Watch.md` as PROPOSED.
Action change: NO — no production adoption action until accepted and available in the targeted toolchain/runtime.

### 5. Swift Evolution SE-0552 — rounding of Float.pi

SE-0552 entered active review on 2026-09-22 and runs through 2026-10-06.

The proposal changes the protocol requirement so `FloatingPoint.pi` is no longer required to round toward zero and specifically changes the `Float.pi` value to the closest representable value, aligning with current IEEE 754 guidance. This can matter to exact-value/golden-file/determinism tests that depend on the historical Float bit pattern.

Canonical change: YES — added to `Swift/Evolution-Watch.md` as PROPOSED.
Action change: NO — tracked as a compatibility watch item rather than a current implementation task.

### 6. Asset Library / App Store creative-asset automation — reviewed

Apple's current App Store asset guidance says assets can be submitted through App Store Connect or App Store Connect API and that approved assets are collected in Asset Library. Apple's broader What's New page still describes parts of the Asset Library/product-page-preview rollout as coming during fall 2026.

Canonical handling: recorded with a rollout/availability caution rather than treating the documentation as proof that every account has identical UI/API availability today.

Canonical change: YES — included in `Distribution/App-Store-Connect-and-Submission.md`.
Action change: NO standalone action; APPLE-018 covers API automation/client refresh where applicable.

## Findings reviewed

### 1. Xcode 27.2 JSON project configuration — meaningful new canonical finding

Apple now documents a JSON-based Xcode project configuration file format (`.xcproj`) in Xcode 27.2 beta. It replaces the internal `.pbxproj` configuration file when selected, while remaining inside the normal `.xcodeproj` project bundle.

Apple describes the JSON format as smaller, hierarchical, self-describing, easier to review in source control, less conflict-prone, and easier for coding intelligence agents to edit. Xcode 27 and later can open the new format. Existing projects can convert through Xcode's File inspector and can revert the source-control change if needed.

Canonical change: YES — created `Xcode/Xcode-27.2-Beta.md` and indexed it.
Action change: YES — added APPLE-014 to pilot `.xcproj` only on a controlled branch with build/test/signing/CI and rollback verification.

### 2. Xcode 27.2 Preview MCP improvement — meaningful agent-workflow finding

Xcode 27.2 beta resolves a Preview tooling limitation: `RenderPreview` now returns available render destinations and lets the caller specify the destination. This is useful for coding agents validating UI across device/layout targets rather than accepting an implicit preview destination.

Canonical change: YES — recorded in `Xcode/Xcode-27.2-Beta.md`.
Action change: folded into APPLE-016's Xcode agent validation workflow rather than creating a separate action.

### 3. Xcode 27.2 beta known issues — recorded for troubleshooting

Apple currently documents:
- possible Xcode crashes during code completion when Xcode runs on macOS 27.2 beta, with a documented preference workaround that disables enhanced code-completion ranking assets;
- Device Hub keyboard/mouse input failures for simulator runtimes earlier than iOS 18/tvOS 18/watchOS 11/visionOS 2;
- temporary hardware-keyboard mode persistence after disconnecting a physical device;
- incorrect 27.1 deployment-target reporting in macOS/watchOS/tvOS/visionOS SDKs and possible Mac Catalyst API availability problems at 27.1/27.2 deployment targets;
- simulator runtimes that can reappear after removal/reboot.

Canonical change: YES — recorded as beta troubleshooting context in `Xcode/Xcode-27.2-Beta.md`.
Action change: NO — these are transient beta issues, not standalone implementation projects.

### 5. iOS/iPadOS 27.2 ATT changes in the EU — meaningful platform/privacy change

Apple is changing App Tracking Transparency behavior in the European Union beginning with iOS 27.2 and iPadOS 27.2.

Key verified points:
- the underlying requirement to request ATT permission for tracking remains;
- an alternative ATT system prompt is available in the EU;
- due to legal requirements, only the alternative/full-page prompt is available for apps distributed in Germany, France, Italy, Poland, and Romania;
- the alternative prompt can expose an `Additional Information` text button;
- Apple's ATT API documentation describes the full-page sheet in those five countries and supports `NSUserTrackingMarkdownUsageDescription` for richer explanation;
- in the EU an app can request ATT permission again one year after the previous choice, whether allow or deny, unless the user has globally disabled tracking requests.

Canonical change: YES — created `Privacy/App-Tracking-Transparency-iOS-27.2.md` and indexed it as BETA.
Action change: YES — added APPLE-015 for apps using ATT/advertising attribution/cross-company tracking.

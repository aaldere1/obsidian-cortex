# Agent Handoff Contract

Use this when turning knowledge into work for another implementation agent.

## Required handoff
```text
ID:
Title:
Why:
Status:
Priority:
Target repo/feature:
Deployment gate:
Relevant knowledge:
Implementation outline:
Acceptance criteria:
Performance verification:
Primary sources:
Risks / rollback:
```

## Rules
- Link to the canonical knowledge page instead of pasting an entire research summary.
- Separate "candidate improvement" from "confirmed bug".
- Never order an agent to use a beta API unless the task is explicitly a beta/forward-compatibility branch.
- Performance actions must specify how success will be measured.
- A visual effect task must include Reduce Motion/accessibility behavior when motion is continuous or significant.
